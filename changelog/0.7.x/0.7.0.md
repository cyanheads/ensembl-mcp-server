# 0.7.0 — 2026-10-28

## Added

- **`ensembl-guide` skill** — served as the `skill://ensembl-guide/SKILL.md` MCP resource (with the `skill://{+path}` template) and shipped in the npm package, Docker image, and plugin installs. It covers confirming a coordinate's assembly, finding a gene's counterpart in another species through homology rather than symbol lookup, reading multi-allelic and capped VEP results, and which Ensembl object level holds the UniProt, RefSeq, GO, and PDB references.
- **Agent Plugins root `plugin.json` and `mcp.json`** (scaffolded by mcp-ts-core 0.13.18).

## Changed

- **mcp-ts-core ^0.13.16 → ^0.13.18.** The HTTP transport no longer retains about 71 KiB per request, which grew the heap under sustained traffic (mcp-ts-core 0.13.17, cyanheads/mcp-ts-core#786). It brings MCP SDK `@modelcontextprotocol/server` ^2.4.0.
- **The `.mcpb` bundle drops the framework's build-only files** (mcp-ts-core 0.13.18, cyanheads/mcp-ts-core#791) **and keeps the MCP SDK's skills runtime** (`dist/ext/skills/`), which the resynced bundle cleaner would otherwise strip — a local fix for cyanheads/mcp-ts-core#794 with a regression test.
- **Docker image** copies `skills/` and labels itself `ensembl-mcp-server` (OCI title, previously the scoped package name).
- **Framework skills and scripts resynced**; `add-skill` added. `minimumReleaseAge` in `bunfig.toml` is 1 day.
- **README** Getting started condensed to the hosted and `npx` setups; **`docs/design.md`** corrects the non-vertebrate limitation (the default endpoint serves those genomes; homology from a non-vertebrate gene stays in its division).
