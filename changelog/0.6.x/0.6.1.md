# 0.6.1 — 2026-10-18

## Added

- **Transcript identity:** lookup records expose optional `canonicalTranscript` and transcript `parentGeneId`; expanded transcripts and VEP consequences retain MANE Select accessions, with optional VEP `canonical` flags. ([#48](https://github.com/cyanheads/ensembl-mcp-server/issues/48))
- **Homolog identity:** optional `targetProteinId` chains to protein sequences; `targetSymbol` enriches returned rows within one five-second budget. Missing names or lookup failures retain every homolog. ([#49](https://github.com/cyanheads/ensembl-mcp-server/issues/49))
- **Cross-reference scope:** `all_levels:true` includes transcript and translation references for a gene, independently of `dbname`; default object-level scope is preserved. ([#46](https://github.com/cyanheads/ensembl-mcp-server/issues/46))

## Changed

- **Batch lookup:** accept up to 1,000 submitted IDs or symbols, resolve the first 20 distinct trimmed queries, and return unattempted queries in `batch.omitted` for resubmission. ([#50](https://github.com/cyanheads/ensembl-mcp-server/issues/50))
- **Desktop bundle:** exclude development sources, tests, caches, scripts and docs.
- **Release procedures:** sync `git-wrapup` 1.30 → 1.31 and `release-and-publish` 2.24 → 2.25, including pre-commit snapshot gates and image-only repair guidance.

## Fixed

- **VEP annotations:** preserve flat SIFT/PolyPhen prediction-score pairs, including zero scores, and aggregate clinical significance; request HGVS annotations on ID, HGVS and region routes. ([#44](https://github.com/cyanheads/ensembl-mcp-server/issues/44))
- **Allele attribution:** retain record `alleleString`, consequence `variantAllele`, explicit per-allele clinical terms and their reference allele without inferring significance for unannotated alleles. ([#45](https://github.com/cyanheads/ensembl-mcp-server/issues/45))
- **Empty region guidance:** a supplied biotype filter is named as a possible cause, with case-sensitive examples and removal guidance instead of an intergenic inference. ([#47](https://github.com/cyanheads/ensembl-mcp-server/issues/47))
